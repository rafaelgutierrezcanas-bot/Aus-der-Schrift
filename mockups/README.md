# Mockups-Ordner

## Zweck

Hier liegen eigenständige HTML-Dateien, die Interaktionselemente visuell darstellen. Sie dienen als Vorschau, bevor der Inhalt in die strukturierten `content/`-Dateien übertragen wird.

## Nutzung

Mockup öffnen:

```bash
open mockups/dateiname.html
```

Jede HTML-Datei ist komplett eigenständig (kein Build nötig) und kann direkt im Browser betrachtet werden.
